# Creative Studio

Take a **Single photo**, choose a treatment, and wait for the shared preview to update. Use **Download photo**, **Download on phone**, or **Print** for the selected version. Tap **Original** to return to the camera JPEG. A render starts when selected and is reused for the same original and treatment version.

- **Portrait Atlas** keeps the main image intact within an editorial layout and ranks detail crops using image contrast and texture. Portrait and landscape photos use different layouts.
- **Parallel Portrait** aligns a silver-toned photograph with a color-relief version made from multiscale contours and offset color masks.
- **The Film Frame** uses a 2.39:1 image window, local color grading, deterministic grain, and a matte. Tall photos get extra framing space to retain the whole subject.
- **Classic Filter** keeps the original local preview’s image preparation, color grade, and JPEG settings.

**New Year Frames** groups eleven single-photo designs, including **Festive Pine Cones · Portrait** and **Fireworks Celebration · Portrait** at the supplied 1024 × 1536 dimensions. Festive Pine Cones retains the soft, semi-transparent sky-blue transition around its rounded photo opening. Fireworks Celebration uses the supplied RGBA PNG unchanged, including transparency throughout the top and all soft transitions, with the photograph behind the entire canvas. **Bright Blue · 2027**, **Vibrant Celebration · 2027**, and **Cozy Winter · 2027** retain the supplied 1536 × 1024 artwork and fit the photo to the right-hand opening. English and Turkish names and descriptions use the shared translation catalogs. The lettering in the supplied artwork stays unchanged.

**Colorful 2027 · Portrait** retains the supplied 1023 × 1538 canvas. Only its black middle photo opening becomes transparent; the white and cream decorative backdrop, colored artwork and thin outer border remain opaque. Its preparation mask is constrained to the dark opening while the original RGB pixels are retained.

Both **Hazar Frames** and **New Year Frames** show a sample thumbnail for every design, ordered portrait first and landscape second, with the existing order retained within each orientation. Opening a collection loads the thumbnails without rendering the customer's photo or changing the selection. The cached JPEG samples use bundled offline photography and the production renderer, preserve each print's aspect ratio, and have a maximum edge of 360 pixels. `/api/sessions/current/photos/creative/frames/{treatment}/preview` serves only these public samples; customer-photo previews still require the owning session.

Rebuild these overlays with `.venv/Scripts/python scripts/prepare-new-year-single.py SOURCE_DIRECTORY`, where the directory contains the original supplied PNGs. Use `--artwork ARTWORK_ID ...` to rebuild selected designs. The script preserves the original RGB pixels and applies checked-in alpha masks in `scripts/new-year-single-masks/` for Bright Blue and Vibrant Celebration. For Festive Pine Cones, it recovers the sky-blue opacity from the flattened black matte and removes that matte from the blue foreground colors; every intermediate alpha value is retained, while all pixels outside the photo opening remain identical to the supplied artwork. **Cozy Winter and Fireworks Celebration are copied byte-for-byte from their supplied RGBA PNGs**, preserving all native alpha values without thresholding, generated replacement masks, or opaque-header overrides. For Fireworks Celebration, place the corrected RGBA attachment in the source directory as `2027 Celebration Beneath Fireworks (1).png`; the earlier flattened RGB download is rejected. Both designs use render version 2 so selecting them refreshes previously prepared results. The mask directory records the preparation details.

The Creative Studio migration adds `creative_results` and references for the existing phone and print queues. Creative JPEGs are stored in the processed folder. The original and legacy files stay in their existing locations. A saved Cinematic portrait from the earlier preview appears as Classic Filter in its active session, and existing QR links keep their configured expiry. The photo booth retains saved images for manual owner management.

**AI Preview** is informational. Classic Filter and the other three treatments run locally in Pillow without provider credentials. The former `PHOTOBOOTH_AI_MODE` setting can be removed from local configuration.

## Verify

- In both shooting sections, check the red **New Year Frames** button with its 34px party-popper icon and 24px confetti extending 14px beyond the border. A short pop, glow and confetti burst plays once when the button enters view; opening the gallery or switching languages must not replay it. Reduced-motion mode retains the static design. Frame preview dimensions and aspect ratios remain unchanged.
- In Multi-Photo Studio, switch from **Motion Study** to **New Year Frames**. Opening the collection immediately selects its first frame and replaces the previous mode's description, layout controls and composition preview. Closing and reopening the gallery retains the chosen New Year frame; choosing another collection closes the gallery. On desktop, Signature Strip and the three side-by-side Creative Collection buttons align with the New Year button and fill the same height.
- Run the backend renderer tests to check orientation, deterministic output, print sizes, and Classic Filter parity.
- Run the PostgreSQL and Angular suites to check retries, selected-result routing, access isolation, and the existing single-photo and filmstrip flows.
- In the booth, preview all four outputs and switch between the original and a treatment. Scan a phone QR on the local network and confirm that **Print** and **Download photo** use the same result shown in the preview.
